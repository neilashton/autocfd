Submission information

About abstract submissions

Due to the large number of registered contributors and limited speaking slots, participants submitting results were also asked to submit a 250-word PDF abstract describing their preliminary findings and methodology (download the abstract template). The organising committee uses a light peer-review process to select speaking slots. Each contributor is assigned an ID for result submissions and cross-plotting.

Abstract submissions are now closed. For questions about an existing submission, email admin@autocfd.org.
